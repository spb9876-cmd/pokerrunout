# 10x this

Take whatever the user pointed at — an idea, a feature, this whole product — and
rebuild it at ten times the ambition. This is not a polish pass and not a
critique. The output must be a different, bigger thing that the original turns
out to have been a small first step toward.

## How to do it

1. **Find the kernel.** Strip the idea to the one insight that makes it worth
   anything. Ignore its current form entirely — the form is what gets replaced.
2. **Name the market-sized version.** Ask: if this kernel were the founding
   insight of a category-defining product, what would that product be? Who wins
   or loses if it exists? What does nobody else own?
3. **Rebuild from the kernel, not the artifact.** Propose the 10x version as
   pillars — each one a capability that would justify the product on its own.
   Every pillar must be concrete enough to start building, not a buzzword.
4. **Carry one thread back to reality.** End with a staged path where the FIRST
   stage is buildable from what exists today. Ambition without a first step is
   a poster; ship the bridge.
5. **Deliver it as a real document.** Publish the vision as a designed artifact
   page the user can share, and give the terminal a tight summary: the one-line
   thesis, the pillars, and what you would build first.

## Rules

- Do not modify or discard working code as part of this pass — the 10x rebuild
  is of the idea; the codebase is the foundation the first stage builds on.
- No hedging language. The vision states what the product becomes, not what it
  "could maybe explore."
- At least one pillar must be something no obvious competitor can copy.
- If the user then picks a pillar, start building it.
